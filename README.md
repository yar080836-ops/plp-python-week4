# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Overview
This repository contains solutions for the Python Week 4 assignment focusing on functions, parameters, return values, and default parameter values.

## Files Description
- `welcome.py`: Refactors repeated code into a reusable `welcome()` function that returns personalized greeting messages.
- `toolbox.py`: Contains utility functions `double()` to double a number, `is_pass()` to evaluate passing scores, and `greet()` to generate customizable greetings.

## Reflection
The `greet()` function with the default parameter was the trickiest to write initially because it required understanding how default values work when arguments are omitted. However, using string interpolation made formatting the output clear and straightforward.
